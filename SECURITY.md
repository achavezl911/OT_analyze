# Seguridad

Este repositorio es **privado** y contiene una herramienta interna de assessment OT. Los datos de los clientes
(capturas, reportes, exportaciones) **nunca** deben estar en él.

- **Reportar una vulnerabilidad o una fuga de datos:** en privado, al propietario del repositorio. No abras un
  issue con datos de un cliente.
- **Modelo de amenazas, controles y debilidades conocidas:** [docs/SEGURIDAD.md](docs/SEGURIDAD.md).
- **Registro de hallazgos y guía de auditoría:** [docs/AUDITORIA.md](docs/AUDITORIA.md).
